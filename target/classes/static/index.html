🛍️ FirstClub Membership Program Java 21 · Spring Boot 3.4 live demo console

Subscription memberships with configurable, tiered benefits — subscribe, upgrade/downgrade, cancel, and earn tiers from your order activity. This page calls the real REST APIs on this server.

1 · Catalogue — plans & configurable tiers

Plans set the billing cycle & price. Tiers grant benefits and are unlocked by configurable rules.

2 · User & orders

Create a user, then place orders. Orders drive tier eligibility (order count & monthly spend).

3 · Subscription lifecycle

Subscribe to a plan; upgrade/downgrade tiers (eligibility enforced); cancel; track current membership.

▶ How to run

  1. Ensure JDK 21+: export JAVA_HOME=$(/usr/libexec/java_home -v 21)
  2. From the project root: ./mvnw spring-boot:run
  3. Open http://localhost:8080/ (this page)
  4. Run tests anytime: ./mvnw test

🎬 Guided demo

One click runs the full happy path end-to-end against the live APIs.
